# Ingeniería en Internet de las Cosas — Proyecto de carrera (UTEQ)

Repositorio de trabajo para el diseño y la presentación al CES del proyecto de la carrera de **Ingeniería en Internet de las Cosas** de la Universidad Técnica Estatal de Quevedo (UTEQ).

## Estructura

| Carpeta | Contenido |
|---|---|
| `01_normativa/CES/` | Reglamento de Régimen Académico (2022 y versión con reforma 2023), Guía Metodológica 2023, Reglamento de Armonización de la Nomenclatura (RPC-SE-05-No.014-2023) |
| `01_normativa/UTEQ/` | Estatuto UTEQ 2019 y PEDI 2021–2025 |
| `02_texto_extraido/` | Texto plano (UTF-8) de cada PDF, para búsqueda. El del Estatuto 2019 viene de un escaneo y tiene errores de reconocimiento |
| `03_analisis/` | Análisis normativo de la creación de la carrera y lista de fuentes |

## Documentos clave

- [Análisis normativo](03_analisis/Analisis_normativo_creacion_carrera_IoT.md): parámetros de diseño, ruta de aprobación, puntos críticos y pendientes de verificación.
- [Fuentes](03_analisis/Fuentes.md): URL de origen de cada archivo y normas descartadas por estar derogadas.
